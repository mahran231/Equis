# ابدأ من هنا | EQUIS BY MAHRAN

23 November 2026 • Specification v1.0 • Preparation only, not a built application

الباكدج دي مواصفات مستقلة لموقع EQUIS والويب آب الخاص بالعميل والكوتش، من الصفر. كل المطلوب مكتوب هنا. مش محتاج ترجع لأي تطبيق منافس أو كود قديم.

## تعمل إيه؟
1. فك ضغط الملف على الكمبيوتر داخل فولدر مشروع جديد وفاضي.
2. افتح الفولدر في Claude Code. احتفظ بملفات الباكدج في `spec/`، ولا تستبدل أي CLAUDE.md موجود من غير مراجعته.
3. انسخ النص الموجود في `01_START_PROMPT.md` إلى Claude Code. أول مرحلة تخطيط وفحص المتطلبات، مش نشر.
4. جهز ملفات هويتك الأصلية، صور التمارين والوصفات المملوكة ليك، وماستر التغذية والتدريب المنقّح بدون بيانات عملاء. القائمة في `08_ASSETS_DECISIONS.md`.
5. Claude يشتغل مرحلة مرحلة، ويطلع الاختبارات والنتيجة الفعلية والنواقص. قبل أي نشر أو بيانات عملاء حقيقيين لازم موافقتك.

ملفات البرمجة بالإنجليزي علشان تكون دقيقة وقابلة للاستخدام المباشر. واجهة العميل المطلوبة عربي مصري RTL، مع English حسب الاختيار.

## جوه الباكدج
- `02_BRD.md`: الهدف، نطاق الشغل، الأدوار وقواعد البزنس.
- `03_FUNCTIONAL_SPEC.md`: المتطلبات والشاشات وسيناريوهات الاستخدام.
- `04_DATA_SECURITY.md`: الداتا والصلاحيات والعزل والعقود المطلوبة.
- `05_TECHNICAL_SPEC.md`: المعمارية، الـAPI، الحسابات والإشعارات والـPDF.
- `06_BUILD_PLAN.md`: خطوات التنفيذ والـprompts المرحلية.
- `07_ACCEPTANCE_TESTS.md`: اختبارات القبول والإطلاق.
- `08_ASSETS_DECISIONS.md`: الملفات والقرارات الناقصة، من غير اختراع تفاصيل.
- `09_SOURCES.md`: المراجع التقنية والملاحظات.
- `requirements.json`: قائمة متطلبات قابلة للتتبع آليًا.
- `CLAUDE.project-template.md`: تعليمات خاصة بالمشروع ده فقط.

## مهم قبل البداية
دي مواصفات، مش سورس كود جاهز ومش إثبات إن التطبيق اتعمل أو اتجرّب. مفيش حد يضمن صفر bugs. الأمان وصحة الحسابات والـPDF لازم يتثبتوا باختبارات فعلية. أي بند pending يمنع إطلاق الجزء المتأثر بيه، مش يمنع بناء الأجزاء المستقلة.

التنفيذ المقترح Web أولًا. المتاجر والنشر المدفوع وتحصيل الأموال أو الاشتراكات الأوتوماتيك خارج الإذن الحالي. مفيش بيانات دخول أو مفاتيح API جوه الباكدج. تدخل محليًا في إعدادات آمنة، مش في الشات أو الـprompts.
